# Rapidpace CRM Demo

Reference email programmes for a crypto + fiat casino, sportsbook and US sweepstakes operator, built for Rapidpace CRM.

Live gallery: https://marcorapidpace.github.io/rapidpace-crm-demo/

- `casino-*`: 26 lifecycle emails (onboarding, 4-deposit welcome package, cashback, VIP, win-back)
- `sports-*`: 19 sportsbook and mixed-vertical emails (onboarding, fiat on-ramp, ACCA boosts, churn, reactivation)
- `sweeps-*`: 16 US sweepstakes emails (Gold Coins / Sweeps Coins, eligibility, verification), each with a plain-text version (`.txt`)

The operator, offers and legal text are fictional and for demonstration only. Templates are standalone HTML for email clients and contain the Rapidpace CRM reserved footer and subscription placeholders.
